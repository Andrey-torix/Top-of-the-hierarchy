# Вершина иерархии — Angular

Адаптивный сайт книги «Вершина иерархии» на Angular 21.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm start
```

Откройте адрес, который покажет Angular CLI (по умолчанию `http://localhost:4200`).

## Production-сборка

```bash
npm run build
```

Результат сборки появится в `dist/top-of-the-hierarchy/browser`.

## Структура

- `src/app/pages/home` — главная страница.
- `src/app/pages/about` — описание книги.
- `src/app/pages/download` — страница загрузки.
- `src/app/app.routes.ts` — маршрутизация.
- `src/styles.css` — общие стили: токены цветов, шрифты, шапка, кнопки, заголовки, подвал.
- `src/app/pages/*/*.component.css` — стили конкретной страницы.
- `src/assets/img/summit.webp` — иллюстрация, которая используется на сайте (`game.png` — исходник, в сборку не попадает).
- `src/assets/fonts` — локальные файлы шрифтов.

## Автономные шрифты

Оба семейства подключаются через локальные `@font-face` в `src/styles.css` по абсолютному пути `/assets/fonts/...` — тот же путь указан в `<link rel="preload">` в `src/index.html`, поэтому шрифты загружаются один раз:

- Fedra Sans Pro (`.woff2`)
- Sprite Graffiti (`.woff2`)

Сетевые шрифтовые сервисы и CDN не используются. В сборку (`angular.json` → `assets`) копируются только эти пять файлов `.woff2`; остальные форматы из `src/assets/fonts` в `dist` не попадают.

## Примечание о скачивании книги

В исходных материалах не было файла книги или ссылки на него, поэтому страница `/download` показывает честный статус публикации. Чтобы включить реальное скачивание, добавьте файл в `src/assets/files` и замените информационный блок на ссылку вида `/assets/files/имя-файла.pdf`.
